# Project MEDICUS - Front End

This project encompasses the essence of creating a Tele Health Web Applications.

## Technical Stack

- NodeJS (v: 14)
- NextJS (v: 12)
- ReactJS (v: 17)
- Typescript (v: 4.5)
- GraphQl (URQL)
- Ant Design (v: 4)
- Tailwindcss (v: 3)
- SCSS (v: 1.4)

## Setup Guide

- Use Node v14> [Download Nodejs](https://nodejs.org/en/download/), or you can use nvm to switch between different versions of node.
- `npm run setup` for installing the packages.

## Available Scripts

In the project directory, you can run:

| Commands                                      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm install`                                 | Runs for installation dependencies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `npm run dev`                                 | Runs the app in the development mode. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `npm run analyze`                             | Runs for analyze the bundle size of application.
